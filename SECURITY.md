# Security

Do not publish API keys, private pages/PDFs, raw extension storage, or browser profiles in Issues, screenshots, or pull requests.

If a key was exposed, revoke it in the DeepSeek platform before sharing diagnostic details. Deleting a file or commit does not revoke a leaked key.

Use GitHub's **Report a vulnerability** feature if the repository maintainer enables private vulnerability reporting. If it is unavailable, open only a non-sensitive Issue asking for a private contact channel; do not publish exploit details or credentials.

This personal project has no security SLA and is not a hardened environment for confidential documents. See PRIVACY.md for storage and upload boundaries.
