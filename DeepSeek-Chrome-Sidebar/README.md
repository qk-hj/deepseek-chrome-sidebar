# DeepSeek 侧栏助手

一个本地运行的 Chrome 扩展：自动拾取网页选文，读取当前网页或 PDF，在浏览器右侧栏调用 DeepSeek API。

## Installation (Chrome)

1. Open `chrome://extensions/`.
2. Turn on **Developer mode** (top right).
3. Click **Load unpacked**.
4. Select the `DeepSeek-Chrome-Sidebar` folder (not the ZIP file).
5. Click **Extensions** in the toolbar, then **Pin** next to this extension.

## 首次使用

1. 点击扩展图标打开右侧栏。
2. 点击右上角齿轮。
3. 填写自己的 DeepSeek API Key（不要把 Key 发给其他人）。
4. 点击“测试连接”，成功后点击“保存”。

获取 API Key：<https://platform.deepseek.com/api_keys>

## 使用

### Update to 0.8.3

If you already loaded this folder: open `chrome://extensions/`, find **DeepSeek 侧栏助手**, and click **Reload** (the circular arrow). Close the sidebar, refresh the webpage, then click the blue D to reopen it. Your API Key and saved conversations are preserved. No new permissions are required.

For the ZIP download: extract it, then use **Load unpacked** and select its `DeepSeek-Chrome-Sidebar` folder. To preserve existing extension storage, update the files in your originally loaded folder and use **Reload**, rather than uninstalling the extension.

- 在普通网页选中文字，输入框内自动显示“1 个选中内容”，不需要右键；再次选文替换上一段。悬停预览原文，点击可固定展开，Escape 或点击外部收起，× 清除。自动拾取不弹提示、不抢焦点。
- 每次发送问题都会读取当前标签页的正文、标题和网址；上方会显示“当前页面 · 页面名称”。
- 切换标签页或跳转后，会跟随当前页面更新。每个问题最多读取 45,000 字符正文和 30,000 字符选文。
- 支持在线和本地文字型 PDF：按页提取论文内容，发送给模型时附页码。解析使用随扩展打包的 PDF.js 6.3.289，需使用新版 Chrome。
- 本地 PDF：在扩展 **Details → Allow access to file URLs** 开启访问权限，然后重新打开侧栏，点击“重新读取”。Chrome 的官方权限说明：https://developer.chrome.com/docs/extensions/develop/concepts/declare-permissions
- 如未开启本地权限、在线文件下载失败或页面要求登录，点击侧栏“选择 PDF”载入下载的文件。选中的文件与当前标签页绑定；侧栏关闭后需要重新选择。
- 解析成功会显示“PDF · 文件名 · 页数”。同一篇 PDF 缓存在侧栏内存中；“重新读取”按钮可重新下载解析。读取失败时展开“查看原因”可看完整错误。
- 每份 PDF 最大 60 MB，所有页的文字都在本机提取和索引，不再到 180,000 字符就停止。扫描件、图表图像和加密文件暂不支持。
- 长 PDF 默认采用 **按需阅读**：初始发送入口页和分布在全文的章节线索，DS 可调用全文搜索、按页读取（含后半部分及末尾）、查看章节概览。每次最多读取 8 页；特别长的页提供后续偏移量继续读。每个问题最多 8 轮工具查阅，到上限时要求模型注明未核查的范围。
- **全文阅读（较慢）**：首次将所有页分批发给模型，生成带页码的通用笔记。同一正文、同一模型的后续问题复用笔记，不重复扫描全部原文；中断后保留已完成批次。剩余超过 8 批时先确认费用。最多缓存最近 3 份文档，缓存位于浏览器会话存储，关闭浏览器或 Reload 扩展后清除；正文或模型变化会重新建立笔记。笔记是有损摘要，具体条件和精确引用仍需按页核查。复用笔记仍会产生回答及按需查阅的 token 费用。
- 阅读过程中显示当前搜索词、查阅页码或全文阅读批次进度。停止按钮会取消 API 请求；批次失败不会声称已经通读。
- Chrome 自带 PDF 阅读器中的选文暂不能自动拾取；仍可以针对整篇内容提问，例如“第 1 页的第一作者来自什么单位”。
- 同一标签页中点击链接、跨站跳转、进入学院网站、前进/后退，都延续当前对话。
- 从页面点击链接新开的标签页（含继续点链接打开的下一层标签页）继承并共用原对话。新标签页中的追问，切回原标签页时也能看到。
- 手动新建的无关联标签页单独聊；在任一标签页点侧栏 **＋** 可主动建立独立对话，不会再次自动继承。后台通过 Chrome 的标签页来源和导航事件记录链接关系。
- 每次提问读取当前页面，并携带当前对话最近的讨论。历史用户消息注明当时阅读的来源，帮助区分先前页面和当前页面。读取失败时不会发送旧页面正文。
- 右上角 **☰** 打开历史列表，可搜索、恢复、重命名和删除。点击“删除”后再次点击“确认删除”才会移除这一条。
- 只有发送过问题的对话才进入历史。仅打开页面、选文或点 **＋** 不产生历史记录；未发送的草稿在当前浏览器会话暂存。旧版已有的空记录自动隐藏。
- **＋** 在当前标签页新建独立对话，旧对话保留在历史列表中。点击历史项只恢复聊天，并把它设为当前标签页的对话；浏览器保持在你正在看的页面，不跳转原网站。
- 已发送的对话、选文和 API 工具子轮保存在本机 `chrome.storage.local`；未发送的空对话草稿使用 `storage.session`，关闭 Chrome 或 Reload 扩展后清除。请求在字符预算内保留最近最多 10 轮，界面历史不截断。旧版对话仍可恢复；缺失思考的旧答复以参考材料带入，不伪造思考字段。
- 手动选择的 PDF 使用文件名、大小和修改时间识别同一份文件；重开侧栏后再次选择同一文件，可接着原对话聊。PDF 原文不写入对话历史。
- 目前不能自动点击链接或执行网页操作。
- 自动选文与正文提取排除输入框及可编辑区域；主动右键带入是用户明确选择。跨网站嵌入 PDF 先确认。读取、解析和生成均可停止，但“停止”不代表所有任务都能暂停后原地继续。
- 工具原文累计预算约 72,000 字符，单次结果最多约 12,000 字符；上下文超过约 140,000 字符停止工具查阅并提示范围不足。这是保守字符估算，不是精确 token 计费或模型容量承诺。回答被截断、响应异常结束和历史保存失败均明确提示。

- 在普通网页中选中文字，右键选择“用 DeepSeek 提问”。
- 或者选中文字后按 `Alt+Shift+D`。
- 在右侧栏输入问题；也可以直接使用“解释、总结、翻译、核查”。
- 普通回车发送，`Shift+Enter` 换行。
- 生成过程中点击方形按钮可停止。

## 隐私边界

- API Key 保存在 `chrome.storage.local`，即当前 Chrome 配置文件的扩展存储中。
- 对话、选中文字和草稿保存在 `chrome.storage.local`，关闭浏览器后仍然保留，可在对话历史中删除；自动选文交接使用 `chrome.storage.session`。
- 提问时会把当前网页或 PDF 提取的文字、标题、来源、选中文字、问题和当前对话的上下文发送到 `https://api.deepseek.com`。PDF 原文件不会上传。
- 选文自动拾取只在本机暂存；你点击发送或快捷提问按钮后才会发送给 DeepSeek。没有第三方统计代码。
- 本地存储不等同于加密保险箱；不要在不受信任的电脑上保存 API Key。

## 联网搜索（实验）

- 输入框上方的“联网搜索”默认关闭；开启后先让模型根据问题和当前页面生成搜索问题，通过 DeepSeek 官方 Anthropic 兼容接口的搜索工具核实，再综合回答。继续使用现有 DeepSeek Key，不调用第三方搜索服务。
- 深度思考开启时使用自动工具选择，避免 API 拒绝强制 `tool_choice`；不会偷偷关闭深度思考。如果模型没有调用搜索，回答会注明未联网核实。
- 每次问题最多发起 3 次搜索请求，每次官方搜索工具最多使用 3 次。会增加 API 请求、Token 用量和等待时间；停止生成同时取消正在执行的搜索请求。
- 回答下方的“联网来源”最多展示 5 个链接，优先回答/搜索摘要实际引用的来源；合并仅有锚点或常见跟踪参数区别的重复链接。来源不足时不凑数，旧历史也按此规则显示。搜索内容和次数不受这个展示上限影响，搜索摘要不等于已完整读取所有来源网页。
- 只将模型生成的搜索问题发送到搜索接口；问题可能含当前页面或选文中的关键词。开启搜索前，请确认允许这些信息发送给 DeepSeek。
- 官方文档说明其 Anthropic 兼容服务提供搜索，但本插件的具体服务端调用契约尚未用真实账户验证。目前通过的是模拟接口、错误处理和界面回归测试，不保证每个模型/账户都可用。接口拒绝请求、没有搜索结果或搜索失败时会明确提示，不会冒充联网成功。
- 参考：https://api-docs.deepseek.com/quick_start/agent_integrations/claude_code/ 、https://api-docs.deepseek.com/guides/anthropic_api/

## 模型自动发现

- 填写 API Key 后自动调用 DeepSeek 官方 `GET /models`，不再内置两款固定模型。接口返回的新模型会自动出现在下拉列表，显示名与实际请求 ID 分开处理。
- 打开设置时自动刷新，也可点击“刷新模型列表”；侧栏启动使用六小时内的缓存，缓存过期后自动更新。不发送聊天内容，也不会为检测模型发起聊天请求。
- 模型列表缓存绑定 Key 的 SHA-256 指纹，不额外存储原始 Key；更换 Key 后重新检测，旧请求结果不会覆盖新 Key 的列表。
- 已保存的模型选择不会被自动替换。若已不在列表中，会标注“未在列表中”，请主动选择新模型；网络异常、无效 Key 或空列表不会清空已有选择。
- 模型发现目前仅针对 DeepSeek 官方接口，不支持截图中的 Anthropic、多供应商或模型角色映射。

## 默认设置

- 模型：首次从 API 返回的可用模型中选择第一项；以后保留用户选择。
- 深度思考：关闭
- 复杂问题可在设置里启用深度思考，或从自动发现的列表中选择其他模型。模型列表发现不等同于自动判断所有模型的参数能力。

## 当前限制

- `chrome://`、Chrome 扩展商店等受保护页面不允许扩展读取选中文字。
- API 可用性、速度和费用取决于 DeepSeek 服务及账户状态。
- 这是本地加载版本；修改文件后需要在 `chrome://extensions/` 中点击扩展卡片上的“重新加载”。
